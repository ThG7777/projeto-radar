# Projeto Radar

to pensando em criar uma ferramenta, um programa, que faz basicamente o seguinte: utiliza grupo de whats e telegram para postar links de produtos como afiliado, tanto mercado livre como  shopee. a ideia é pagar trafego no instagram para conseguir que entrem no grupo. a ideia é que ele pesquise produtos que realmente estejam em promoção, com bons descontos, diversos, não sei se é o caso de focar num determinado tipo de produto. pelo que vi, outros grupos publicam produtos no geral. a partir daí o programa deve pesquisar produtos em promoção, que tenha bons numeros de vendas, talvez uns 30, 40 produtos por dia. qual seria a quantidade ideal? me ajude a estruturar. o programa deve achar o produto, abrir o produto ou  a pagina de afiliados para conseguir o link do afiliado, criar um anuncio com baner que seja interessante comercialmente e seja vendável, para que esse produto seja enviado para o grupo de ofertas. pesquisar cupons também para informar junto ao anuncio. me ajude na estruturaçao.
